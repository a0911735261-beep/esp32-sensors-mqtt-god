WHY THIS PROJECT

小型裝置，也能有完整的資料流。

從感測器、微控制器、無線網路到視覺化輸出，每一層都保持簡單、透明，適合學習、展示與後續改造。

01

多感測輸入

DHT11 讀取溫度與濕度，光敏電阻提供 0～1000 的相對亮度值。

02

低功耗顯示

Waveshare 2.9 吋黑白紅三色電子紙，讓資訊在斷電後仍能保留。

03

MQTT 控制

週期發布資料，也能用 ON、OFF、TOGGLE 指令控制外部燈號或繼電器。

DATA PIPELINE

一條簡潔的 MQTT 資料管線。

ESP32 每 60 秒發布感測值，同時訂閱燈號控制主題。你可以把它接到 Node-RED、Home Assistant 或任何 MQTT client。

OUTesp32/epaper/temperature溫度 °C
OUTesp32/epaper/humidity相對濕度
OUTesp32/epaper/lux相對亮度
INesp32/epaper/light/setON / OFF / TOGGLE
STATEesp32/epaper/statusONLINE / OFFLINE
